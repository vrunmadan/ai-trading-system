STEP 0
Portfolio Risk Gaterules

Runs first, before anything else. Deterministic circuit breakers, checked in severity order. Any trip → whole cycle halts + Gmail alert. If the check itself errors → fail-safe, no trade.

Circuit breakers (halt if…)

  • Drawdown ≤ −8% below all-time peak
  • Weekly realised P&L ≤ −₹15,000
  • Deployed capital ≥ 65%
  • Open positions ≥ 6
  • Any sector > 30% of capital

How value is tracked

  • Portfolio = capital + all realised P&L
  • Peak stored in SQLite, bumped on new highs
  • No live-price fetch here — simple & reliable
  • Base capital: ₹10,00,000
✓ approved
STEP 1
Regime Classifierrules · not an LLM

Deterministic math on live Kite data → one of 5 regimes. Reproducible & auditable by design.

3 inputs (weighted composite score)

  • Nifty 50 vs 200-day EMA (weight ≈3)
  • India VIX level + 5-day trend (≈2.5)
  • Breadth: % of ≤20 tickers above 50-SMA (≈2)

Key thresholds

  • VIX: calm<15 · elevated<20 · high<25 · extreme≥30
  • Nifty bands: euphoria+8% · bull+2% · bear−3% · crash−12%
  • Breadth: bull≥65% · weak<40%

5 regimes & overrides

  • 🚀 Euphoria · 🟢 Bull · 🟡 Sideways · 🟠 Bear · 🔴 Crash
  • Hard override: VIX ≥30 OR Nifty ≤−12% → forced Crash regardless of score
  • Inertia: needs 2 consecutive matching reads to switch regime; mid-transition it holds the prior regime and drops confidence −25 (anti-whiplash)
⛔ Gate: regime confidence < 60% → cycle skipped.
✓ confidence ≥ 60%
STEP 2
Signal Generatorpython + Claude Sonnet 5

Regime picks a strategy basket. Python computes all indicators; Claude does pure synthesis (no live API calls — data is passed in as text, keeping every signal auditable).

Strategy baskets by regime

  • Bull: 52wk_breakout, supertrend_buy
  • Sideways: rsi_mean_reversion
  • Bear / Crash / Euphoria: empty → no new longs, cycle ends

Indicators (Python)

  • RSI-14 (Wilder), Supertrend(10,3)
  • Volume ratio 20d, % from 52wk high
  • Bollinger position, SMA-50/200, ATR%
  • + Google News RSS: macro / sector / company

Claude's job & scoring rubric

  • “Reject far more often than you approve.” 75%+ = genuinely exceptional.
  • confidence = 0.6 × technical + 0.4 × fundamental; fundamental starts at 60 (neutral), adjusted by news
  • Scans every ticker × strategy → keeps the single highest-confidence signal. Every eval logged to cycle_log.
⛔ Gate: verdict must be TRADE AND confidence ≥ 75% — else None, cycle ends. Frequency is an output, never a target.
✓ 1 signal ≥ 75%
STEP 3
Risk Sizerrules · no LLM ever

The “compliance desk.” 6 checks in severity order — returns on first failure — then confidence-scaled sizing.

Reject if…

  • Weekly P&L < −10% of capital
  • Already ≥ 5 concurrent positions
  • Already holding this ticker (no pyramiding)
  • Sector already ≥ 35% of capital
  • Free capital < ₹10,000

Sizing formula

  • Base = 20% of capital per trade
  • Confidence scale: 70%→0.60×, 100%→1.00×
  • Capped at free-capital×0.95 & sector headroom
  • Final < ₹10k after caps → reject
Trader fills exact share quantity later at live price — sizer only decides ₹ to deploy.
✓ approved & sized
STEP 4
QC / Fact-CheckerGPT-5.5 · adversarial

Independent lab, on purpose. Its only job is to try to falsify the thesis — checks technical claims vs numbers, unverifiable fundamentals, regime mismatch, narrative/recency bias, sector risk. Must log disconfirming evidence even on AGREE.

Verdicts

  • AGREE → proceed
  • DISAGREE → block
  • NEEDS_MORE_DATA → block

Fail-safe

  • Missing API key, parse error, API outage → forced NEEDS_MORE_DATA
  • i.e. a broken QC blocks the trade — never ships it
⛔ Gate: only AGREE passes.
✓ AGREE
